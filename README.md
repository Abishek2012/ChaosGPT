# js-intro-repo

A code repo for initial JavaScript projects.

## Interactive Calculator

This repo includes a small browser-based calculator in `index.html`, with styles in `styles.css` and calculator behavior in `script.js`.

### Run it locally

You can open the app directly in a browser or start a local static server for a browser URL.

#### Option 1: Open the HTML file

1. In your file explorer, open this repository folder.
2. Double-click `index.html`.
3. The calculator will open in your default browser.

#### Option 2: Use a local server

From the repository root, run:

```bash
python3 -m http.server 4173
```

Then open this URL in your browser:

```text
http://127.0.0.1:4173/index.html
```

To stop the server, press `Ctrl + C` in the terminal.
