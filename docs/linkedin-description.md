# LinkedIn project description

AegisML is a portable MLOps platform for operating a real-time transaction-risk API. It connects model validation and MLflow promotion with immutable-image GitOps delivery, Kubernetes reliability controls, Prometheus/Grafana observability, OpenCost-informed unit economics, and opt-in chaos experiments. The focus is practical operational trade-offs: use measured signals to protect a 99.9% successful-inference SLO while making reliability and scaling cost visible.
